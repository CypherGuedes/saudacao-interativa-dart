# Saudação Interativa em Dart

Projeto introdutório desenvolvido durante os estudos de Dart para praticar os primeiros conceitos da linguagem por meio de uma aplicação executada no terminal.

O programa apresenta uma mensagem inicial, solicita o nome do usuário e utiliza o valor informado para gerar uma resposta personalizada.

## Objetivo

Praticar fundamentos essenciais de Dart antes do avanço para aplicações mais completas e para o desenvolvimento com Flutter.

## Conceitos praticados

- estrutura básica de um programa em Dart;
- função `main()`;
- saída de dados com `print()` e `stdout.write()`;
- entrada de dados pelo terminal com `stdin.readLineSync()`;
- declaração de variáveis com `final`;
- interpolação de strings;
- tratamento simples de entrada vazia ou nula;
- execução de aplicações Dart pelo terminal.

## Funcionamento

Ao executar o programa, o usuário recebe uma pergunta solicitando seu nome. Depois da entrada, o programa exibe uma saudação personalizada.

Exemplo:

```text
Olá, me chamo Dart. Qual é o seu nome? Thiago
Muito prazer, Thiago. Vamos fazer vários programas juntos!
```

## Como executar

É necessário ter o Dart SDK instalado.

No terminal, acesse a pasta do projeto e execute:

```bash
dart run bin/saudacao_interativa.dart
```
